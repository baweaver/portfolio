Good call on puts returning nil, that’s always a fun one when getting started. You could use p instead which would return the value and log it, I use it sometimes to debug.

Enumerable in Ruby is full of all types of fun methods, especially for practicing against. If you start taking all of those methods and reimplementing them using each it gives a lot of fun insight. You could also do it with reduce, but that’s a whole new bit of fun.

Keep up the good work!
